# Security

MacRemote reads your remote with Input Monitoring and controls the Mac with
Accessibility, so security problems matter. Thank you for reporting them.

## Reporting a problem

Please do not open a public issue. Report it privately instead:
**Security → Report a vulnerability** on the repository page
(https://github.com/giovannilattanzio/MacRemote/security/advisories/new).

Say what you found, the steps to reproduce it, and the MacRemote and macOS
versions. You will get an answer as soon as possible.

## Supported versions

Only the latest release on GitHub Releases gets fixes.
